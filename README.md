# 🎮 Rock Paper Scissors Game

## Description
A fun Rock Paper Scissors game built using HTML, CSS, and JavaScript where users play against the computer and track their scores.

## Purpose
The purpose of this project is to practice JavaScript functions, conditional statements, random number generation, DOM manipulation, and event handling by creating an interactive game.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Play Rock, Paper, and Scissors against the computer
- Computer generates a random choice
- Displays win, lose, and draw results
- Tracks user and computer scores
- Reset Game button to restart the scores
- Responsive design for different screen sizes

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Select Rock, Paper, or Scissors to play.
5. Check the result and scores.
6. Click **Reset Game** to start again.
